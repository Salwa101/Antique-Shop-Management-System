# Antique Shop Management System

## Introduction
The Antique Shop Management System is a desktop-based application developed using Java in NetBeans IDE and SQL database. This system helps manage antique shop operations such as product management, customer records, inventory control, and sales management.

## Features
- User Login System
- Add, Update, Delete Products
- Manage Customer Information
- Inventory Management
- Sales Record Management
- Bill/Invoice Generation
- SQL Database Connectivity

## Technologies Used
- Java
- NetBeans IDE
- SQL

## Software Requirements
- JDK 8 or above
- NetBeans IDE
- MySQL Server

## Database Setup
1. Open MySQL.
2. Create a new database.
3. Import the provided SQL file.
4. Update database username and password in the project source code.

## How to Run
1. Open the project in NetBeans IDE.
2. Connect the project with MySQL database.
3. Build the project.
4. Run the application.


## Purpose
The main purpose of this project is to simplify antique shop management and reduce manual work by using a computerized system.
